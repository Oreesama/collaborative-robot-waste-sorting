\# Sensor-based Approach for Manipulation Tasks Execution with a Collaborative Robot



This project implements a sensor-based autonomous waste sorting system using a collaborative robot.

The system relies on a YOLO-based object detection pipeline to identify different types of waste and estimate their position in the workspace. Based on this perception output, the robot performs motion planning and executes grasping actions using ROS and MoveIt, enabling automated pick-and-place sorting into predefined categories.

The project was developed as part of a master’s thesis titled:
“Sensor-based Approach for Manipulation Tasks Execution with a Collaborative Robot”

Developed by Bey Ishak and Siffedine Seray under the supervision of Dr. Akli Isma at CDTA Algiers during the academic year 2023/2024.
